# Security notes

Follow these precautions when configuring or extending KSA Free Bot.

- Keep `.env` private. It contains the bot token.
- If the token is ever shared, reset it immediately in the Discord Developer Portal.
- Give the bot only the permissions listed in `README.md`.
- Download updates only from the official repository you trust.
- Review third-party code before adding it to this bot.
- Do not add features that collect passwords, private messages, or unnecessary personal information.

## Reporting a security problem

Contact KSAGlory privately through [discord.gg/ksahub](https://discord.gg/ksahub). Do not open a public issue containing a token, private configuration, or other sensitive information.
